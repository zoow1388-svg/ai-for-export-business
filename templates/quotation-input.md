## 虚构教学数据

| 字段 | 演示值 |
| --- | --- |
| 版本/日期 | Q-DEMO-001 / 2026-10-11 |
| 产品/单位/数量 | FR-10 / 件 / 1,000 |
| MOQ | 500 件 |
| 单价/币种 | 3.80 USD/件 |
| 包装 | 每件纸套已含在单价中；20 件/箱 |
| 折扣 | 仅对货值减 2.50%，演示已批准 |
| 一次性费用 | 制版费 60.00 USD，演示已批准，不参与折扣 |
| 运输、保险、税费 | 未确认，不包含在已知费用小计中 |
| 贸易术语与地点 | 未确认 |
| 付款、交期 | 未确认 |
| 有效期 | 演示有效至 2026-10-25；其余条件待确认后再形成正式报价 |

计算口径：货值 = 数量 × 单价；折扣 = 货值 × 2.50%；已知费用小计 = 货值 − 折扣 + 制版费。金额保留两位小数；装箱数 = 1,000 ÷ 20 = 50 箱。

**复核值：货值 3,800.00 USD，折扣 95.00 USD，折后货值 3,705.00 USD，已知费用小计 3,765.00 USD。** 该小计不是含税、含运费的到岸总价。
