# AI 外贸实战指南：从客户研究到客服回复

面向外贸业务员、工厂销售、跟单和客服团队，把 AI 用到开发信、翻译、客户研究、产品资料、报价和客服这六类日常工作。

由 [TOOLBBS](https://www.toolbbs.com/) 整理与维护。

**首版内容：6 份操作指南、4 份输入模板、7 组可复制提示词、14 个官方来源和 3 篇经核验的中文补充教程。**

**检查日期：2026-10-11（America/Chicago）。** 本项目提供独立的业务步骤、教学示例和验收条件。来源阅读、本机链接访问结果及未执行的验证见 [来源与检查记录](docs/SOURCE_CHECK.md)。

## 第一次练习怎么做

1. 打开一份指南，先读“适用条件”，确认你已有需要的资料。
2. 将指南中的整段提示词复制到公司允许使用的 AI 工具。示例输入已经写全，可以先用虚构资料练习。
3. 把回答与“教学示例”及“验收与异常处理”逐项对照。遇到未知信息，保留未知并补资料。
4. 换成自己的资料前，去掉客户姓名、联系方式、账户、真实订单号、底价和不允许上传的信息。
5. 人工核对规格、金额、认证、交期和客户身份后，再通过正常业务渠道使用结果。

本仓库内的公司、产品和报价数据均为虚构教学资料；期望输出由维护者编写，**未作为某一平台实测效果或真实成交案例**。本次没有登录 AI 平台执行这些流程，没有发送客户邮件、提交报价、接入订单或启用客服自动化。

## 工具与费用怎么判断

普通邮件、改写和资料整理可以先在公司允许使用的对话工具中手工完成。文件上传、联网搜索、术语表和知识库属于需要单独确认的能力；各指南提供对应官方说明。

- 本次未确认你的账号资格、所在地区价格、实际可用额度或数据保留配置；不要把“能打开帮助页面”理解为功能已经开通。
- DeepL 的文件和术语表能力、Dify 的模型与知识库额度、n8n 的工作流执行量各有条件。以检查记录链接的官方页面与账号实际显示为准。
- 先验证少量虚构样例，再处理经允许的业务资料。Dify 与 n8n 的进阶步骤需要熟悉配置的人参与，不要求新手先部署服务器。
