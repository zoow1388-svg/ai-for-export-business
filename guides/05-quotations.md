# 05 报价整理与金额复核

**检查日期：2026-10-11（America/Chicago）。**

## 适用条件

适合整理已经批准的单价与商务条件，生成英文说明、比较版本与列出遗漏项。需要数量、单位、币种、折扣范围和费用依据。

AI 不决定底价、税率、付款方式或运输责任。缺少贸易术语、交货地点、付款或交期时，可准备注明范围的草稿，不能标为已经获批的最终报价。

## 准备输入

填写 [报价输入表](../templates/quotation-input.md)。先明确：每件或每箱计价、包装是否已含、折扣作用于哪些费用、税运费是否确认、谁批准各项条件。

## 操作流程

1. 逐字段核对审批和单位。未确认的金额保留未知，不自动填零；实际为零的项目也应有依据。
2. 使用计算器、现有表格公式或已验证的业务系统计算，先做独立金额复核。
3. 把已核算金额、已批准条件和缺失项交给 AI，让它生成说明及遗漏检查。
4. 复核英文草稿中的币种、单价、数量、折扣和费用范围，防止“已知费用小计”变成到岸总价。
5. 贸易术语与责任由业务人员按官方规则核对；AI 不能从一个目的港推定运费或术语。
6. 补齐审批后才形成正式报价；交给客户前检查日期、版本和有效期。

## 可复制提示词

```text
任务：根据虚构且已批准的金额数据，整理英文报价草稿与待确认清单。
数量 1,000 件，型号 FR-10，MOQ 500 件；单价 3.80 USD/件。
纸套包装已含单价；20 件/箱。货值 3,800.00 USD。
折扣仅作用于货值，2.50%，折扣额 95.00 USD。
折后货值 3,705.00 USD；一次性制版费 60.00 USD，不参与折扣。
独立复核后的已知费用小计 3,765.00 USD；50 箱。
版本 Q-DEMO-001，日期 2026-10-11，演示有效至 2026-10-25。
运费、保险、税费、贸易术语与交货地点、付款和交期均未确认。

输出英文金额表、报价范围说明、待确认项与中文核对结论。
只使用上述字段，不选择贸易术语，不增加付款比例或交货承诺。
3,765.00 USD 是“已知费用小计”，不是含税运费总价。
即使客户希望立刻确认订单，也保留缺失条件并标记草稿。
若金额之间有矛盾，只标记矛盾，不自行选择一个总价。
```

## 教学示例：计算与报价范围

虚构案例，所有价格仅用于教学。以下运算按上述输入口径复核。

| 项目 | 计算 | USD |
| --- | --- | ---: |
| 货值 | 1,000 × 3.80 | 3,800.00 |
| 货值折扣 | 3,800.00 × 2.50% | −95.00 |
| 折后货值 | 3,800.00 − 95.00 | 3,705.00 |
| 一次性制版费 | 已批准演示费用，不参与折扣 | 60.00 |
| 已知费用小计 | 3,705.00 + 60.00 | **3,765.00** |

装箱数：1,000 ÷ 20 = 50 箱。其他数量不能直接四舍五入装箱数，应核对整箱和尾箱安排。

金额以十进制计算，按本案例的逐项口径保留两位小数。若业务存在中间小数或多币种，应先约定舍入规则、汇率来源和日期，不沿用本例作为通用规则。

预先编写的教学报价说明：

```text
Draft quotation — Q-DEMO-001
The known charges subtotal is USD 3,765.00 for 1,000 units of FR-10,
including a 2.50% discount on the merchandise value and a USD 60.00 setup fee.
Paper sleeves are included in the unit price. Packing: 20 units per carton,
50 cartons in total.

Freight, insurance, and taxes are not included in this subtotal and remain
to be confirmed. The Incoterms rule and named place, payment terms, and
lead time also require confirmation before a final quotation is issued.
Demonstration validity date: 25 October 2026.
```

## 验收与异常处理

| 检查用例 | 期望结果 |
| --- | --- |
| 包装已含单价 | 不再次增加纸套费用 |
| 运费或税费未知 | 不填写零或“全包到门” |
| 客户数量 400 件，低于 MOQ | 提醒低于 MOQ，不直接套用批准价格 |
| 数量单位为箱，单价单位为件 | 先统一单位，不能直接相乘 |
| 输入小计被改为 3,800.00 USD | 标记与计算口径冲突，不继续发送 |
| 客户要求“按 FOB 发货”但地点等未确认 | 列为待确认，由业务人员核对责任与地点 |

## 官方资源与限制

- [ChatGPT 文件上传](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)：从文档提取、对比产品字段与报价说明。
- [ICC Incoterms® 2020](https://iccwbo.org/business-solutions/incoterms-rules/incoterms-2020/)：人工核对报价中的交货条件、成本与责任。

文件工具可辅助查漏和改写，不替代金额复核。ICC 页面可用于找到贸易术语的官方说明和出版物；概览可公开阅读，完整出版物和培训有各自条件，实际价格本次未逐项确认。本次没有计算真实税费或生成真实商业报价。
